#### Description

The `google search-console sites` command group manages your verified sites in Google Search Console. You can list all sites, get details for a specific site, add new sites, or remove existing ones.

Available subcommands:

- **list** — List all verified sites
- **get** — Get information about a specific site
- **add** — Add a site to Search Console
- **delete** — Remove a site from Search Console

#### Usage

```bash
aux4 google search-console sites <subcommand>
```

#### Example

```bash
aux4 google search-console sites list
aux4 google search-console sites get https://example.com
```
